What it does not do yet, and what comes next

Limitations

  • Three documents by design: EU CTR, GVP modules and FDA rules are refused or answered only from what E6(R3) says
  • Multi-hop questions: one retrieval pass misses a hop — the reporting chain still lacks the 15-day timeline
  • The refusal gate is corpus- and model-specific: change either, recalibrate
  • Memory lives in the process; a restart forgets the threads
  • Free tier: 1,000 embedded texts per day — the corpus build used 800 of them once, so query vectors are cached too

Next steps, in order of value

  1. Query decomposition: one retrieval per step of a multi-hop question
  2. EMA GVP Module VI and EU CTR 536/2014 — ingestion is per document and idempotent
  3. LLM-as-judge faithfulness check on the golden set (keywords are a proxy)
  4. Hybrid retrieval (BM25 + vectors) for exact section numbers and acronyms
  5. A guard_input node (prompt injection, PII) and SqliteSaver for persistent threads
