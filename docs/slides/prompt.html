The system prompt: each version answers an observed failure

v1 · class baseline

“Answer from the documents”

  • Correct and fluent, but no citation markers: no sentence can be traced to a passage
  • No rule for missing information, no scope, no language policy

v3 · citations and language

[n] on every sentence, sources attributed, answer in the user’s language

  • The golden-set run found: a multi-step question refused outright
  • Its Spanish refusal written in English
  • Truncated lists presented as complete

v4 · in use

Graded refusals, multi-step answers, complete lists

  • Answer the covered part, name the uncovered part; refuse only when nothing is relevant
  • Build chains step by step, citing each step
  • Give every list item, or say the list continues — in the user’s language

Hard constraints in code, judgement in the prompt. The answer language is a deterministic line in the user message, out-of-domain questions never reach the model, and truncated lists were fixed in retrieval (section expansion), not with more prompt.

Full prompt and rationale: README · docs/prompt_iterations.md (v2 was a design step, not evaluated on its own)

Cuatro versiones; enseño tres. La versión uno, el prompt de clase, respondía bien pero sin marcas de cita: nada era trazable. La versión tres añadió citas por frase, atribución cuando los documentos difieren y la política de idioma. Entonces ejecuté el golden set completo y leí todas las respuestas: una pregunta de varios pasos se rechazó aunque todos los pasos estaban en los pasajes; su rechazo en español salió en inglés; y listas cortadas por el troceado se presentaban como completas. La versión cuatro gradúa el rechazo (responde la parte cubierta y dice cuál no), construye las cadenas paso a paso y pide listas completas. El recorte de las listas lo arreglé en la recuperación, no en el prompt: las restricciones duras van en código y el criterio va en el prompt.
