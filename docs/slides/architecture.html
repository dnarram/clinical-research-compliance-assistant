Idempotent knowledge base

801 chunks, gemini-embedding-2. A versioned embedding cache + manifest: nothing is re-embedded, and Chroma rebuilds from it with zero API calls — on Streamlit Cloud too.

Calibrated refusal gate

Gemini cosine scores sit in a narrow band. The threshold (0.69) is read off in-domain vs out-of-domain queries, not guessed; MMR gives multi-document coverage.

Memory that stays small

LangGraph checkpointer per thread_id; the last 10 messages reach the model; retrieved passages live in state, not in the history.

Stack: Gemini 3.5 Flash-Lite · gemini-embedding-2 · ChromaDB · LangGraph · Streamlit — github.com/dnarram/clinical-research-compliance-assistant

Why an explicit graph and not a tool-calling agent: the brief requires the knowledge base on every query, the free tier makes every extra model call expensive, and a fixed topology is easy to trace. The question is rewritten into a standalone English question, retrieval scores it and gates it, and the router sends it to generate or to a templated refusal that never touches the model. Three decisions: the versioned embedding cache, the calibrated threshold, and the memory window with context kept out of the history.
