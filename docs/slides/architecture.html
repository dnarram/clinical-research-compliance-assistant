Idempotent knowledge base

801 chunks, gemini-embedding-2. A versioned embedding cache + manifest: nothing is re-embedded, and Chroma rebuilds from it with zero API calls — on Streamlit Cloud too.

Gate calibrated on data

Threshold 0.69 read off in-domain vs out-of-domain queries, not guessed. Then a metadata filter for documents the question names, and each chunk widened to its section so lists arrive whole.

Memory that stays small

LangGraph checkpointer per thread_id; the last 10 messages reach the model; retrieved passages live in state, not in the history.

Gemini 3.5 Flash-Lite · gemini-embedding-2 · ChromaDB · LangGraph · Streamlit — github.com/dnarram

Tres documentos públicos, 801 fragmentos, cada uno con documento, sección y página. Los documentos se descargan de los editores y se verifican con su huella; Helsinki se indexó desde la web porque el PDF estropea los números de párrafo. Descarté el agente que decide por sí mismo si busca: el enunciado exige usar la base en cada consulta. El agente es un grafo fijo de cuatro nodos: reescribir, recuperar, generar, rechazar. La reescritura convierte la pregunta, con el historial, en una pregunta autónoma en inglés: así resuelve «¿y para las demás?» y salva el idioma del corpus. La recuperación tiene cuatro etapas. Primero, la puerta: si la mejor puntuación no alcanza 0,69, la pregunta se rechaza con una plantilla sin llamar al modelo; lo que no llega al modelo no se puede inventar. Segundo, si la pregunta nombra documentos, las seis plazas se reparten entre ellos. Tercero, diversidad. Cuarto, la etapa más útil: cada fragmento se amplía a su sección completa. Nació de un fallo real: la definición de «grave» tiene cinco criterios, el fragmento traía dos y el modelo la daba por completa. No se arregla pidiéndoselo, porque no puede completar lo que no ve; se arregla entregándole la sección entera. Tres decisiones que defiendo: una caché de embeddings versionada, porque el plan gratuito permite mil textos al día y el corpus consume ochocientos; un umbral calibrado con datos, no fijado a ojo; y una memoria de diez mensajes que mantiene los pasajes fuera del historial.
